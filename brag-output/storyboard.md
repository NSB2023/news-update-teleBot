# MorningBird launch video

Square social video, 1080 × 1080, 15 seconds. Five scenes run for three seconds each. Narration generated locally with Pocket TTS using the Caro Davy voice. The configuration screen is a capture of the actual MorningBird UI. The Telegram scene is an illustrative mockup.

1. **0:00–0:03 — The idea.** Newspaper hero art and “The world. On your way.”
2. **0:03–0:06 — Configure.** Actual newspaper-style setup interface with regions, topics and sources.
3. **0:06–0:09 — The pipeline.** RSS → local Qwen → local Pocket TTS → Telegram.
4. **0:09–0:12 — Delivery.** Illustrative Telegram chat with three voice briefings.
5. **0:12–0:15 — Close.** MorningBird title and project URL.

The full production assets are in `source/`: `slides.html`, `hero.png`, `interface.png`, and `narration.wav`. Open `slides.html?slide=1` through `?slide=5` in a browser to view individual scenes.

The website uses `morningbird-launch-wide.mp4`, a true 1280 × 720 version composed from the same five scenes and original narration. Open `slides.html?slide=1&wide=1` through `?slide=5&wide=1` to inspect its source frames. The original square film remains available separately.
